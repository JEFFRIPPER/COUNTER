# COUNTER V2

Счётчик рабочих коммуникаций для Windows 10/11. Интерфейс Material Design 3, светлая и тёмная темы, локальное сохранение. Программа поставляется **одним `COUNTER.exe` (около 379 КБ)**: интерфейс и библиотеки WebView2 встроены в него.

![Интерфейс COUNTER V2](docs/preview.png)

## Скачать и открыть

- [COUNTER.exe](https://github.com/JEFFRIPPER/COUNTER/raw/refs/heads/main/dist/COUNTER.exe)
- [Все файлы проекта](https://github.com/JEFFRIPPER/COUNTER/archive/refs/heads/main.zip)

Для копирования всего проекта в **`C:\Users\User\Desktop\COUNTER V2`** распакуй архив и запусти `COPY-TO-DESKTOP.cmd`. Программа окажется в `COUNTER V2\dist\COUNTER.exe`. Копирование не удаляет другие файлы в папке. Для использования отдельно достаточно одного EXE из `dist`.

Системные компоненты: .NET Framework 4.8 и Microsoft Edge WebView2 Runtime. Среда .NET обычно уже входит в актуальные Windows 10/11; [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) устанавливается отдельно, если отсутствует. Программа не требует .NET SDK, Node.js или подключения к интернету.

## Что сохранено

- Категории: НДЗ, Перезвон, Успешно, Отказ, VIP, Блокировка, Сам, Трансфер. Добавление, удаление, изменение числа и перетаскивание строк.
- «Всего коммуникаций» — сумма категорий. «Коммуникации» — отдельный независимый счётчик.
- Профили, отмена последних 50 действий и история последних 30 завершённых смен.
- Начало, пауза, продолжение, завершение смены, заметки и автоматическое завершение по заданному времени.
- Цель 140, успешность, темп, копирование отчёта и CSV с русскими названиями.

## Дизайн и анимации

Семантические цветовые роли MD3, тональные поверхности, крупные числовые значения, скруглённые карточки, filled/tonal/outlined-кнопки и диалоги. Отклик кнопок, анимация чисел, прогресса и появления элементов работают без внешних шрифтов, картинок и CDN. Системная настройка уменьшения анимаций учитывается. Звук можно включить в настройках; по умолчанию он выключен.

Ориентиры: [цвета Material 3](https://m3.material.io/styles/color/the-color-system), [анимации Material 3](https://m3.material.io/styles/motion/easing-and-duration/tokens-specs). Компоненты реализованы в HTML/CSS/JS для настольной оболочки WebView2.

## Данные и компактная поставка

Рядом с EXE не нужны `index.html`, `.config` или DLL. При запуске нативный загрузчик WebView2 извлекается в `%LOCALAPPDATA%\COUNTER\Runtime`, браузерные данные находятся в `%LOCALAPPDATA%\COUNTER\WebView2`. JSON-копию профилей можно сохранить и загрузить в настройках. Эти служебные файлы создаются автоматически; браузерная среда может занимать больше места, чем сам EXE.

Ключи прежнего HTML (`commProfiles`, `commStatsData_<профиль>`, `commStatsTheme`) сохранены; также поддерживается прежний одно-профильный `commStatsData`. Они переносятся, если доступны в текущем хранилище. Хранилище старой оболочки рядом с её EXE автоматически не переносится в новый каталог: при наличии важной статистики оставь старую версию до переноса данных.

Исправлены восстановление паузы после перезапуска, независимость снимков отмены, сохранение отменённого действия, переименование профиля и завершение ночной смены. Пользовательские названия и заметки выводятся текстом.

## Сборка

На Windows с .NET Framework 4.8 (SDK не требуется; при первой сборке загружается зафиксированный пакет WebView2):

```powershell
.\build.ps1
```

Сборка и копирование всего проекта в указанную папку:

```powershell
.\build.ps1 -Install
```

Другой путь для локальной копии:

```powershell
.\install.ps1 -Destination 'D:\COUNTER'
```

Исходники — `src/index.html`, `src/Counter.cs`, `src/app.manifest`. Версия и SHA-256 пакета WebView2 зафиксированы в `build.ps1`. Интерфейс и зависимости сжимаются GZip и встраиваются в EXE. `bin`, `obj` и `node_modules` не входят в распространяемое приложение.

## Проверка

```powershell
npm install
npx playwright install chromium
npm test
.\dist\COUNTER.exe --smoke-test
```

Проверки интерфейса охватывают сохранение и переименование профилей, независимые счётчики, ручное изменение, отмену, паузу после перезапуска, ночные смены, CSV, прежние данные, работу без внешних запросов и компактное окно. Native smoke test запускает EXE в отдельном временном хранилище, проверяет загрузку встроенных ресурсов и работу счётчика; возвращает 0 при успехе. GitHub Actions выполняет сборку и эти проверки на Windows.

Репозиторий изначально был пустым. Основой служит прежний `index.html` программы «СЧЁТЧИК», обновлённый 6 октября 2026. Приложенный `DynamicIsland.exe` относится к отдельной программе и в эту сборку не включён.
